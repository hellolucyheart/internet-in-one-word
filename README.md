The whole internet in one word: **pandemonium** — a roaring crowd, everyone shouting at once, a capital of demons holding a permanent convention. It makes a reader laugh and then nod, which is exactly what the brief asks for.

`main.py` scores a shortlist of candidate words against the five published judging criteria — single word, funny, true, surprising, lands in one beat — and writes the deterministic winner to `/output/entry.txt`. The obvious words (feral, brainrot, doomscrolling, enshittification, unhinged, slop) are scored honestly and rejected: each is funny and true, but each is the first word anyone reaches for and each is already an entry many times over.

## Run it

```sh
python3 main.py
```
